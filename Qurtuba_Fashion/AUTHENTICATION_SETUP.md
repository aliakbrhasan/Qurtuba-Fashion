# 🔐 دليل إعداد نظام المصادقة

## 📋 نظرة عامة

تم تطوير نظام مصادقة كامل ومتقدم لنظام خياطة قرطبة يتضمن:

- ✅ تسجيل دخول آمن مع قاعدة البيانات
- ✅ تشفير كلمات المرور باستخدام SHA-256
- ✅ ميزة "تذكرني" مع localStorage
- ✅ إدارة المستخدمين والأدوار
- ✅ حماية الصفحات حسب الصلاحيات
- ✅ واجهة مستخدم محسنة

## 🚀 إعداد قاعدة البيانات

### 1. إنشاء المستخدم الافتراضي

قم بتشغيل الأمر التالي لإنشاء المستخدم الافتراضي:

```bash
node create-default-user.js
```

ثم انسخ والصق SQL الناتج في محرر SQL في Supabase.

### 2. بيانات تسجيل الدخول الافتراضية

- **البريد الإلكتروني**: `admin@qurtuba.com`
- **كلمة المرور**: `admin123`
- **الصلاحية**: مدير النظام (ادمن)

## 🔧 الميزات الجديدة

### 1. خدمة المصادقة (`src/services/auth.service.ts`)

```typescript
// تسجيل الدخول
const result = await authService.login({
  email: 'admin@qurtuba.com',
  password: 'admin123',
  rememberMe: true
});

// إنشاء مستخدم جديد (للمدير فقط)
const newUser = await authService.createUser({
  code: 'EMP001',
  name: 'اسم الموظف',
  email: 'employee@qurtuba.com',
  password: 'password123',
  status: 'موظف',
  role: 'مندوب مبيعات'
});
```

### 2. نافذة تسجيل الدخول المحسنة

- ✅ التحقق من صحة البيانات
- ✅ رسائل خطأ واضحة
- ✅ حالة تحميل أثناء تسجيل الدخول
- ✅ ميزة "تذكرني" فعالة
- ✅ تسجيل دخول تلقائي للمستخدمين المحفوظين

### 3. حماية الصفحات

```typescript
// حماية صفحة تتطلب تسجيل دخول
<ProtectedRoute>
  <YourComponent />
</ProtectedRoute>

// حماية صفحة تتطلب صلاحية محددة
<ProtectedRoute requiredRole="ادمن">
  <AdminOnlyComponent />
</ProtectedRoute>
```

### 4. عرض معلومات المستخدم

- ✅ اسم المستخدم في Header
- ✅ نوع الصلاحية
- ✅ صورة رمزية للمستخدم
- ✅ معلومات كاملة في القائمة الجانبية

## 🛡️ الأمان

### 1. تشفير كلمات المرور

- استخدام SHA-256 لتشفير كلمات المرور
- لا يتم حفظ كلمات المرور كنص واضح
- التحقق الآمن من كلمات المرور

### 2. إدارة الجلسات

- حفظ آمن لبيانات المستخدم في localStorage
- انتهاء صلاحية الجلسات بعد 30 يوم
- تسجيل خروج آمن مع مسح البيانات

### 3. التحكم في الصلاحيات

- ثلاثة مستويات صلاحية: ادمن، موظف، محاسب
- حماية الصفحات حسب نوع المستخدم
- منع الوصول غير المصرح به

## 📱 تجربة المستخدم

### 1. تسجيل الدخول السريع

- تسجيل دخول تلقائي للمستخدمين المحفوظين
- واجهة سهلة الاستخدام
- رسائل واضحة للحالات المختلفة

### 2. التنقل المحسن

- عرض معلومات المستخدم في كل مكان
- أزرار تسجيل الخروج في مواقع متعددة
- قوائم تنقل محمية حسب الصلاحيات

## 🔄 إدارة المستخدمين

### 1. إنشاء مستخدمين جدد

```typescript
// للمدير فقط
const result = await authService.createUser({
  code: 'EMP002',
  name: 'اسم الموظف',
  email: 'employee2@qurtuba.com',
  password: 'securePassword123',
  status: 'محاسب',
  role: 'محاسب مالي'
});
```

### 2. تحديث المستخدمين

```typescript
// تحديث معلومات المستخدم
await authService.updateUser(userId, {
  name: 'الاسم الجديد',
  status: 'موظف'
});

// تحديث كلمة المرور
await authService.updatePassword(userId, 'newPassword123');
```

### 3. حذف المستخدمين

```typescript
// حذف مستخدم (للمدير فقط)
await authService.deleteUser(userId);
```

## 🎯 أنواع المستخدمين

### 1. مدير النظام (ادمن)
- ✅ وصول كامل لجميع الميزات
- ✅ إدارة المستخدمين
- ✅ إدارة الأدوار والصلاحيات
- ✅ جميع التقارير والإحصائيات

### 2. موظف
- ✅ إدارة العملاء
- ✅ إنشاء الفواتير
- ✅ إدارة الطلبات
- ❌ لا يمكنه إدارة المستخدمين

### 3. محاسب
- ✅ إدارة الفواتير
- ✅ التقارير المالية
- ✅ إدارة المدفوعات
- ❌ لا يمكنه إدارة العملاء

## 🚨 استكشاف الأخطاء

### 1. مشاكل تسجيل الدخول

**المشكلة**: "البريد الإلكتروني أو كلمة المرور غير صحيحة"
**الحل**: تأكد من:
- صحة البريد الإلكتروني
- صحة كلمة المرور
- أن المستخدم مفعل في قاعدة البيانات

**المشكلة**: "حدث خطأ أثناء تسجيل الدخول"
**الحل**: تأكد من:
- اتصال قاعدة البيانات
- صحة متغيرات البيئة
- تشغيل Supabase

### 2. مشاكل الصلاحيات

**المشكلة**: "ليس لديك صلاحية للوصول"
**الحل**: تأكد من:
- نوع المستخدم في قاعدة البيانات
- الصلاحية المطلوبة للصفحة
- تحديث معلومات المستخدم

### 3. مشاكل "تذكرني"

**المشكلة**: لا يتم حفظ تسجيل الدخول
**الحل**: تأكد من:
- تفعيل localStorage في المتصفح
- عدم وجود إعدادات خصوصية تمنع الحفظ
- مسح البيانات القديمة
