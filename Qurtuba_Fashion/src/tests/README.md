# اختبارات صفحة إدارة الزبائن

هذا المجلد يحتوي على جميع الاختبارات المتعلقة بصفحة إدارة الزبائن في نظام أزياء قرطبة.

## الملفات الموجودة

### 1. ملفات الاختبار
- `CustomersPage.test.tsx` - اختبارات الوحدة الأساسية
- `CustomersPagePerformance.test.tsx` - اختبارات الأداء
- `CustomersPageIntegration.test.tsx` - اختبارات التكامل
- `CustomersPageTestRunner.tsx` - أداة تشغيل الاختبارات التفاعلية

### 2. ملفات التوثيق
- `CustomersPageTestScenarios.md` - سيناريوهات الاختبار الشاملة
- `README.md` - هذا الملف

### 3. ملفات التشغيل
- `runCustomersPageTests.ts` - سكريبت تشغيل الاختبارات

## كيفية تشغيل الاختبارات

### تشغيل جميع الاختبارات
```bash
npm run test:customers
```

```bash
npm run test:customers:unit
```

### تشغيل اختبارات الأداء فقط
```bash
npm run test:customers:performance
```

### تشغيل اختبارات التكامل فقط
```bash
npm run test:customers:integration
```

### تشغيل الاختبارات مع تغطية الكود
```bash
npm run test:customers:coverage
```

## أنواع الاختبارات

### 1. اختبارات الوحدة (Unit Tests)
تختبر كل دالة أو مكون بشكل منفصل:

- **عرض البيانات**: تحميل وعرض قائمة الزبائن
- **البحث والتصفية**: وظائف البحث والتصفية
- **الترتيب**: ترتيب البيانات حسب معايير مختلفة
- **إضافة زبون جديد**: إنشاء زبون جديد
- **عرض تفاصيل الزبون**: النقر على الزبون لعرض التفاصيل
- **الطباعة**: طباعة قائمة الزبائن
- **الصلاحيات**: التحقق من الصلاحيات

### 2. اختبارات الأداء (Performance Tests)
تختبر أداء الصفحة مع كميات كبيرة من البيانات:

- **أداء العرض**: سرعة عرض 100، 500، 1000 زبون
- **أداء البحث**: سرعة البحث في كميات كبيرة من البيانات
- **أداء التصفية**: سرعة التصفية والترتيب
- **أداء تبديل العرض**: سرعة التبديل بين وضع الجدول والشبكة
- **استخدام الذاكرة**: التحقق من عدم وجود تسريبات في الذاكرة

### 3. اختبارات التكامل (Integration Tests)
تختبر تفاعل المكونات مع بعضها البعض:

- **سير العمل الكامل**: إدارة دورة حياة الزبون
- **تكامل البحث والتصفية**: تفاعل البحث مع التصفية
- **تكامل أوضاع العرض**: الحفاظ على الحالة عند التبديل
- **تكامل الإحصائيات**: تحديث الإحصائيات مع التصفية
- **معالجة الأخطاء**: التعامل مع الأخطاء بشكل صحيح

## سيناريوهات الاختبار

### السيناريو 1: عرض قائمة الزبائن
1. تسجيل الدخول إلى النظام
2. الانتقال إلى صفحة إدارة الزبائن
3. التحقق من تحميل قائمة الزبائن
4. التحقق من عرض الإحصائيات
5. التحقق من عرض البيانات في الجدول

### السيناريو 2: البحث في الزبائن
1. إدخال اسم زبون في مربع البحث
2. التحقق من تصفية النتائج
3. إدخال رقم هاتف في مربع البحث
4. التحقق من تصفية النتائج
5. مسح مربع البحث
6. التحقق من عرض جميع الزبائن

### السيناريو 3: إضافة زبون جديد
1. النقر على "زبون جديد"
2. إدخال البيانات المطلوبة
3. النقر على "حفظ الزبون"
4. التحقق من ظهور الزبون الجديد
5. التحقق من تحديث الإحصائيات

### السيناريو 4: عرض تفاصيل الزبون
1. النقر على صف زبون في الجدول
2. التحقق من فتح صفحة التفاصيل
3. العودة إلى صفحة إدارة الزبائن
4. النقر على بطاقة زبون في الشبكة
5. التحقق من فتح صفحة التفاصيل

## معايير الأداء

### معايير العرض
- **100 زبون**: أقل من 100ms
- **500 زبون**: أقل من 200ms
- **1000 زبون**: أقل من 500ms

### معايير البحث
- **1000 زبون**: أقل من 50ms
- **التغييرات السريعة**: أقل من 100ms

### معايير التصفية والترتيب
- **1000 زبون**: أقل من 50ms

### معايير تبديل العرض
- **500 زبون**: أقل من 100ms
