# 🎯 دليل نظام إدارة الأدوار - Qurtuba Fashion

## 📋 نظرة عامة

تم تطوير نظام إدارة الأدوار الكامل لـ Qurtuba Fashion والذي يتيح:
- إدارة الأدوار والصلاحيات ديناميكياً
- إخفاء وإظهار الصفحات حسب دور المستخدم
- ربط كامل بقاعدة البيانات
- واجهة مستخدم متقدمة لإدارة الأدوار

## 🗄️ قاعدة البيانات

### الجداول الجديدة

1. **`roles`** - جدول الأدوار
   - `id` - معرف فريد للدور
   - `name` - اسم الدور
   - `description` - وصف الدور
   - `permissions` - مصفوفة الصلاحيات العامة
   - `allowed_pages` - مصفوفة الصفحات المسموحة
   - `allowed_actions` - مصفوفة الإجراءات المسموحة
   - `is_active` - حالة النشاط

2. **`pages`** - جدول الصفحات
   - `id` - معرف الصفحة
   - `name` - اسم الصفحة
   - `description` - وصف الصفحة
   - `category` - فئة الصفحة

3. **`actions`** - جدول الإجراءات
   - `id` - معرف الإجراء
   - `name` - اسم الإجراء
   - `description` - وصف الإجراء
   - `category` - فئة الإجراء

## 🚀 إعداد النظام

### الخطوة 1: إعداد قاعدة البيانات

1. **اذهب إلى Supabase Dashboard**
   - انتقل إلى: https://supabase.com/dashboard
   - اختر مشروعك: `dbjaogpesmyrqjwtzzwr`

2. **افتح SQL Editor**
   - اضغط على **"SQL Editor"** في الشريط الجانبي
   - اضغط على **"New query"**

3. **شغل ملف إعداد الأدوار**
   - انسخ محتوى `roles-database-setup.sql`
   - الصقه في SQL Editor
   - اضغط **"Run"** لتنفيذ السكريبت

### الخطوة 2: التحقق من الجداول

اذهب إلى **"Table Editor"** وتأكد من وجود:
- ✅ `roles` - جدول الأدوار
- ✅ `pages` - جدول الصفحات  
- ✅ `actions` - جدول الإجراءات

### الخطوة 3: تشغيل التطبيق

```bash
npm run dev
```

## 🚨 استكشاف الأخطاء

### مشاكل شائعة

1. **لا تظهر الصفحات**
   - تحقق من ربط المستخدم بدور
   - تحقق من إعدادات الدور
   - تأكد من تشغيل قاعدة البيانات

2. **خطأ في تحميل الأدوار**
   - تحقق من اتصال قاعدة البيانات
   - تأكد من تشغيل سكريبت إعداد قاعدة البيانات
   - تحقق من رسائل الخطأ في وحدة التحكم

3. **لا تعمل الصلاحيات**
   - تأكد من تحديث معلومات المستخدم
   - تحقق من إعدادات الدور
   - أعد تحميل الصفحة

### خطوات التشخيص

1. **تحقق من قاعدة البيانات**
   ```sql
   SELECT * FROM roles WHERE is_active = true;
   SELECT * FROM pages WHERE is_active = true;
   SELECT * FROM actions WHERE is_active = true;
   ```

2. **تحقق من المستخدمين**
   ```sql
   SELECT u.*, r.name as role_name 
   FROM users u 
   LEFT JOIN roles r ON u.role_id = r.id;
   ```

3. **تحقق من وحدة التحكم**
   - افتح Developer Tools
   - اذهب إلى Console
   - ابحث عن رسائل الخطأ
