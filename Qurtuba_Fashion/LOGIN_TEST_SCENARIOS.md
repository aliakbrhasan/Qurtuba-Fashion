## 🔐 اختبارات الوظائف الأساسية

### ✅ **السيناريو 1: تسجيل دخول ناجح**
**الهدف**: التأكد من أن تسجيل الدخول يعمل بشكل صحيح

**الخطوات**:
1. افتح صفحة تسجيل الدخول
2. أدخل البريد الإلكتروني: `admin@qurtuba.com`
3. أدخل كلمة المرور: `admin123`
4. اضغط على "تسجيل الدخول"

**النتيجة المتوقعة**:
- ✅ تسجيل دخول ناجح
- ✅ رسالة ترحيب تظهر
- ✅ الانتقال للصفحة الرئيسية
- ✅ عرض اسم المستخدم في القائمة

**كود الاختبار**:
```javascript
// اختبار تسجيل دخول المدير
const result = await authService.login({
  email: 'admin@qurtuba.com',
  password: 'admin123'
});
expect(result.success).toBe(true);
expect(result.user.name).toBe('مدير النظام');
```

- ✅ عرض صلاحيات الموظف
- ✅ عدم إمكانية الوصول لصفحات الإدارة

### ✅ **السيناريو 3: تسجيل دخول المحاسب**
**الهدف**: اختبار تسجيل دخول المحاسبين

## ❌ اختبارات الأمان

### 🚫 **السيناريو 4: كلمة مرور خاطئة**
**الهدف**: التأكد من رفض كلمات المرور الخاطئة

**الخطوات**:
1. أدخل البريد الإلكتروني: `admin@qurtuba.com`
2. أدخل كلمة مرور خاطئة: `wrongpassword`
3. اضغط على "تسجيل الدخول"

**النتيجة المتوقعة**:
- ❌ فشل تسجيل الدخول
- ❌ رسالة خطأ: "البريد الإلكتروني أو كلمة المرور غير صحيحة"
- ❌ عدم الانتقال للصفحة الرئيسية

**كود الاختبار**:
```javascript
// اختبار كلمة مرور خاطئة
const result = await authService.login({
  email: 'admin@qurtuba.com',
  password: 'wrongpassword'
});
expect(result.success).toBe(false);
expect(result.error).toContain('غير صحيحة');
```

**النتيجة المتوقعة**:
- ❌ فشل تسجيل الدخول
- ❌ رسالة خطأ: "البريد الإلكتروني أو كلمة المرور غير صحيحة"

## 💾 اختبارات نظام "تذكرني"

### 🔄 **السيناريو 11: تفعيل "تذكرني"**
**الهدف**: التأكد من عمل نظام "تذكرني"

**الخطوات**:
1. أدخل بيانات تسجيل الدخول
2. ضع علامة على "تذكرني"
3. اضغط على "تسجيل الدخول"
4. أغلق المتصفح وأعد فتحه

**النتيجة المتوقعة**:
- ✅ تسجيل دخول تلقائي
- ✅ عدم الحاجة لإدخال البيانات مرة أخرى
- ✅ حفظ البيانات في localStorage

**كود الاختبار**:
```javascript
// اختبار نظام "تذكرني"
const result = await authService.login({
  email: 'admin@qurtuba.com',
  password: 'admin123',
  rememberMe: true
});

expect(result.success).toBe(true);

// التحقق من حفظ البيانات
const storedAuth = localStorage.getItem('qurtuba_auth');
const remembered = localStorage.getItem('qurtuba_remember');

expect(storedAuth).toBeDefined();
expect(remembered).toBe('true');
```

**الهدف**: التأكد من انتهاء صلاحية البيانات المحفوظة

**الخطوات**:
1. حفظ بيانات "تذكرني" قديمة (أكثر من 30 يوم)
2. إعادة فتح الصفحة
3. التحقق من عدم تسجيل الدخول التلقائي

**النتيجة المتوقعة**:
- ❌ عدم تسجيل دخول تلقائي
- ✅ مسح البيانات المنتهية الصلاحية
- ✅ عرض صفحة تسجيل الدخول

### 🔄 **السيناريو 13: إلغاء "تذكرني"**
**الهدف**: التأكد من عدم حفظ البيانات عند عدم تفعيل "تذكرني"

**الخطوات**:
1. أدخل بيانات تسجيل الدخول
2. لا تضع علامة على "تذكرني"
3. اضغط على "تسجيل الدخول"
4. أغلق المتصفح وأعد فتحه

**النتيجة المتوقعة**:
- ❌ عدم تسجيل دخول تلقائي
