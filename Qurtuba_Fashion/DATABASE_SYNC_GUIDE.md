# 🔗 دليل مزامنة قاعدة البيانات - Qurtuba Fashion

## ❌ المشكلة الحالية
قاعدة البيانات غير متصلة بسبب مفتاح Supabase وهمي. تحتاج إلى إعداد قاعدة البيانات الحقيقية.

## 🎯 الحل الكامل

### الخطوة 1: إعداد مشروع Supabase

1. **اذهب إلى Supabase Dashboard**
   - انتقل إلى: https://supabase.com/dashboard
   - سجل دخول أو أنشئ حساب جديد

2. **أنشئ مشروع جديد**
   - اضغط على "New Project"
   - اختر منظمة (Organization)
   - أدخل اسم المشروع: `Qurtuba-Fashion`
   - أدخل كلمة مرور قاعدة البيانات
   - اختر المنطقة الأقرب لك
   - اضغط "Create new project"

3. **انتظر إنشاء المشروع**
   - قد يستغرق 2-3 دقائق
   - ستظهر رسالة "Your project is ready"

### الخطوة 2: الحصول على مفاتيح API

1. **اذهب إلى Settings → API**
   - في لوحة التحكم، اضغط على "Settings"
   - اختر "API" من القائمة الجانبية

2. **انسخ المفاتيح المطلوبة**
   - **Project URL**: `https://your-project-id.supabase.co`
   - **anon public key**: `eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...`

### الخطوة 3: تحديث متغيرات البيئة

1. **افتح ملف `.env`**
   ```bash
   notepad .env
   ```

2. **استبدل القيم بالمفاتيح الحقيقية**
   ```env
   VITE_SUPABASE_URL=https://your-project-id.supabase.co
   VITE_SUPABASE_ANON_KEY=your-actual-anon-key-here
   ```

### الخطوة 4: إعداد قاعدة البيانات

1. **اذهب إلى SQL Editor**
   - في لوحة التحكم، اضغط على "SQL Editor"
   - اضغط على "New query"

2. **شغل سكريبت قاعدة البيانات الكامل**
   - انسخ محتوى `complete-webapp-database.sql`
   - الصقه في SQL Editor
   - اضغط "Run" لتنفيذ السكريبت

3. **شغل سكريبت الأدوار**
   - انسخ محتوى `roles-database-setup.sql`
   - الصقه في SQL Editor
   - اضغط "Run" لتنفيذ السكريبت

### الخطوة 5: التحقق من الجداول

1. **اذهب إلى Table Editor**
   - اضغط على "Table Editor" في القائمة الجانبية
   - تأكد من وجود الجداول التالية:
     - ✅ `users`
     - ✅ `roles`
     - ✅ `pages`
     - ✅ `actions`
     - ✅ `customers`
     - ✅ `invoices`
     - ✅ `invoice_items`
     - ✅ `orders`

### الخطوة 6: اختبار الاتصال

1. **شغل الخادم**
   ```bash
   npm run dev
   ```

2. **افتح المتصفح**
   - اذهب إلى: http://localhost:3003
   - سجل دخول باستخدام:
     - **البريد**: admin@qurtuba.com
     - **كلمة المرور**: admin123

3. **اختبر الوظائف**
   - تأكد من ظهور جميع الصفحات
   - اختبر إدارة الأدوار
   - اختبر إدارة المستخدمين
   - اختبر إنشاء الفواتير

## 🔧 استكشاف الأخطاء

### مشكلة: "401 Unauthorized"
**الحل**: تأكد من صحة مفتاح API في ملف `.env`

### مشكلة: "Failed to fetch"
**الحل**: تحقق من اتصال الإنترنت وURL المشروع

### مشكلة: "Table doesn't exist"
**الحل**: تأكد من تشغيل سكريبت قاعدة البيانات

### مشكلة: "No data found"
**الحل**: تأكد من إدراج البيانات الافتراضية
